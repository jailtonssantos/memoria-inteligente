Como funciona

O app usa inteligência artificial gratuita para entender suas perguntas e organizar seus registros.

🔑 Você vai precisar de uma API key gratuita do Groq — é rápido e sem cartão de crédito.
📏 Registros curtos funcionam melhor. Prefira frases diretas como tomei medicação 07h em vez de textos longos.
⏱ Há um limite de uso por minuto — generoso para o dia a dia, mas evite muitas consultas seguidas.

Crie sua API key gratuita

Você precisa fazer isso uma única vez. Leva menos de 2 minutos.

1. Acesse console.groq.com/keys
2. Crie uma conta gratuita (pode usar Google)
3. Clique em Create API Key e copie a key
4. Cole a key na próxima tela e pronto ✅
